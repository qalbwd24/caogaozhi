# 草稿纸 · Windows 桌面预览版

面向 Windows 11 x64 的独立桌面窗口。无需安装 Node.js、Electron 或打开浏览器；程序保存在一个包含全部依赖的便携目录。先解压完整 ZIP，再双击 `草稿纸.exe`，不要将 EXE 单独移出目录。

- 草稿写入本机应用数据，不上传服务器。网页试玩版与 Windows 电脑版不共享本机草稿，可用 JSON 导出和导入。
- 文字、颜色、连线和各草稿标签页自动保存；关闭窗口前会写入尚未保存的修改。`Ctrl+S` 可立即保存，成功时不显示常驻提示。
- `F18` 循环四色，`F17` 循环选中连线的箭头方向；Esc 打开或关闭工具菜单，F19/F20 不占用。不使用系统全局热键。
- `Ctrl+Z` 撤销，`Ctrl+Y` 或 `Ctrl+Shift+Z` 重做；`Tab` 延伸子块，子块可继续延伸。中文候选确认期间不触发结构快捷键。
- 右上角 `⋯ → 保存截图` 或 `Ctrl+Shift+S` 捕捉草稿纸应用内容，不采集桌面或其他窗口。
- 此预览版没有独立的 Windows 代码签名，不是安装器。请从可信来源下载。
- 当前仅构建 x64。没有验证 ARM64、Windows 10 或较早系统。

## 从源码打包

使用 Python 3.11+，联网下载 Electron v45.5.0 官方 Windows x64 运行时并校验发布方 SHA-256。也可用 `--cache 路径` 指向已下载的官方运行时 ZIP 和 `SHASUMS256.txt` 所在目录。

```sh
python desktop/build-windows.py --output ./草稿纸-win-x64.zip
```

ZIP 包括 Electron 及 Chromium 上游许可证。应用源码和网站共用 `dist/` 的页面、脚本和样式；打包会包含完整运行资源，排除测试、截图和临时文件。桌面入口为 `desktop/main.cjs`。

本轮宿主与前端的纸面底色都从暖橘 `#fce3bf` 开始，避免加载时闪白。文档标题由页面更新，并由原生窗口显示；宿主不覆盖用户命名。`F17/F18` 由原生输入转发为一次对应的快捷操作，浏览器版本使用 DOM 按键处理。触控板双指平移、捏合缩放和鼠标操作最终作用于同一个画布。支持的 Windows 11 x64 系统可以从本应用窗口读取原生双指接触点，不对平移锁轴；普通鼠标滚轮和中键仍走原入口。系统或构建缺少原生模块时退回原有行为。

构建脚本与快捷键桥接可在开发环境检查；本轮的实体 Windows 触控板、输入法和用户本地热键映射仍需在 Windows 运行包中复验。

## 原生触控板模块

需要 Zig（在 Windows x64 上使用 0.12.0-dev.1286 验证编译）。打包时传入 `--zig C:/path/to/zig.exe`，会随 ZIP 加入从 `desktop/native/touchpad.c` 编译的模块；不传参数时仍可打包，触控板使用原来的回退路径。模块不需要安装驱动、服务或系统快捷键，只处理前台草稿纸窗口内的双指数据，数据不保存也不上传。可用 `node --test tests/touchpad-motion.test.cjs` 检查转向、捏合与惯性计算；实体触控板需另测。
