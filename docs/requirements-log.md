# 草稿纸 · 需求与改动记录

记录为什么改、旧方案怎么被替换，以及验证到底覆盖了什么。当前用法见 [README](../README.md)，原始想法见 [设计笔记](design.md)，首轮回归见 [v0.3 验证记录](verification-v0.3.md)。不收录私人草稿、设备标识、账户资料或私有链接。

## 2026-11-24：把纸笔习惯变成最少的动作

- 从已有草稿反推连线、颜色、留白、并排、圈画的用途；文字直接落到可扩展画布，不为纸面容量强行分隔。无框表格先用对齐和留白，不急着加专用控件。
- 黑为正文，红为重点、易错和提醒，蓝为新启发和好观点，灰模拟铅笔，留给想法、补注和待定。先以红色合并圈、波浪线、下划线等常见强调动作。
- 点空白即写，空输入离开就释放；Enter 建同级，有 `1.` 可续编号，Shift+Enter 块内换行。Tab 建单箭头子块，也要能继续建子子块，中文候选确认不能误生成结构。
- 从块上拉线，落已有块直接连，落空白建相连块。实线和虚线、无／单／双箭头、颜色各自独立。关系说明可手动附在线上，不凭距离把邻近文字硬判成线标签。
- 场景包括随手发散、多层调研、阅读取材、方案对照与数学推导。纸笔往返、免 LaTeX 数学、按需让 AI 阅读结构是探索方向，不属于首版交付；AI 不应替换原稿。

## 2026-11-25：原型、Windows 交付与迭代

1. **先把功能做全，再减界面。** 实际可启动的 Windows 版优先，网页只是试用。简洁、纸感、无明显边框和占位；顶栏跟随所选对象显示笔色或连线属性；没有常驻保存说明和右下工具，保留错误提示。复杂、多层、长文字和跨线数据要用真实运行画面验收；私人手稿与截图不进公开仓库。
2. **能作为日常编辑窗口。** 自动保存、立即保存、撤销／重做、多标签、自定义名称与关闭后恢复；导入新开标签。不同标签保留各自内容、线、笔色、视野。旧单草稿迁进一个标签，保留旧记录。要求交付 Windows 可运行便携版并在目标电脑部署；套壳包、已安装文件与实机使用是不同的验证结果。
3. **连线先避字，后优先自然。** 最初针对压字做局部绕行，不自动移动文字；实样里碰字减少。用户不喜欢方形绕路，改用自然连续曲线，允许少量交叠。文字是软约束，反向线分开；不要为了零交叠硬折返，也不把所有箭头误当结构层级。
4. **固定棕色点阵、自由平移。** 暖橘纸面参考拾页；20 像素点阵绘在视口层，画布缩放和窗口变化不改变点大小与间距，棕点调淡，不和文字抢视线。加强纸面纹理；可选壁纸层仅从本机读取，不进入公开仓库，也不随草稿画布缩放。触控板要求按原始两个方向移动，捏合缩放；鼠标按住滚轮平移，不用空白左键拖动。空白轻点仍落笔，裸拖保留给后续用途。应用不做轴优先或 Shift 自动改轴；Windows 上游给应用的输入若已经锁轴，仍需原生路径和实体触控板验证。
5. **右键在光标附近，快捷键可完整操作。** 靠窗口边缘时自动换边；键盘唤起获得焦点，↑↓ 切换，Enter 执行，Esc 关闭。F19 打开分层工具菜单，→ 进入，← 返回；分成草稿与标签、编辑与对象、保存与导出、画布与视野和设置。保留 Shift+F10 对象操作。
6. **把点击、拉线、挪块和选字分开。** 用文字块实际渲染范围加少量命中余量；点一下编辑，快速拖动拉线，编辑状态内普通拖动选字。新的挪块方式是悬停至抓手后直接拖动，不再用 Alt+拖动；光标区分可点击、输入、连线和移动。中键拖动画布，普通右键只开菜单，不拿它移动。
7. **换笔和改已有颜色是两件事。** 空白预选、写前、写到一半都能换颜色；移动光标不能把已选笔色恢复成邻近字色。拖选多字后换色只处理选区，且可撤销，不改下一笔。点整块换色需要在对象菜单中明确选择。换色用短小的提示反馈，可在设置关闭；不再给输入状态遮挡性的常驻文字。

## 被替换的方案

| 原先讨论或试用 | 现行要求 |
| --- | --- |
| Caps+Q/E、Alt+Q/E、F17–F20 每色一键 | F17/F18 左右循环四笔色，F19 打开工具，F20 暂留。本地键位映射由用户掌握。 |
| 为压字使用直角绕远、自动全局排版 | 保留布局，自然曲线优先，允许少量压字。 |
| 常驻保存说明、底部工具、明显文本框 | 保留纸面、顶栏和按需菜单；保存失败才额外提醒。 |
| 空白直接拖动画布、尝试右键拖画布 | 鼠标按住滚轮平移；裸拖空白留空。 |
| Alt+拖动文字块挪位置 | 悬停出现抓手后直接拖；快速拖动拉线；编辑中可拖选文字。 |

## 验证与未实现

- v0.3 的验证记录报告 33 项 Chromium 自动化检查，覆盖层级、输入、笔色、历史、标签、迁移、双轴滚动与缩放；另用虚构的多层和密集图试走线。
- 后续在隔离 Windows Electron 窗口测试过旧稿迁移、双标签重载、点阵固定、普通/斜向输入、靠边右键菜单、键盘菜单、拉线、拖到空白建块及颜色操作。测试不写真实用户草稿。
- 模拟组合输入与双轴事件不等于实体中文候选窗、实体触控板或本地键位映射；尤其不能由合成两轴事件推断已解除 Windows 上游锁轴。
- 手写识别、打印回导、同步、数学专用输入、AI 分析和跨重启编辑历史仍未交付。JSON 导出是当前草稿，不是所有标签的完整工作区备份；整块选字改色不等同跨多个文字块框选。

本轮 Windows Electron 隔离回归覆盖半途换笔、移光标保持笔色、鼠标拖选及单步撤销、F19 进入／退出子菜单、快速拖动连线、悬停拖块、双方向键与双轴事件、淡点阵和本地壁纸加载。浏览器输入注入不是实体手势测试。[Chromium Windows 输入实现](https://chromium.googlesource.com/chromium/src/+/HEAD/content/browser/renderer_host/direct_manipulation_helper_win.cc) 可作为原生锁轴调查入口。

### 同日勘误：暖纸不是图案壁纸，实体触控板仍锁轴

- 实际体验反馈：要的是暖色纸张自身的细纹理，不是借用有图案的壁纸。撤下本地壁纸图层和图片读取；底色改为暖米纸，叠加不带图形的细纤维纹，淡棕固定点阵保留。前一节的本机壁纸试做已经被这一决定覆盖。
- 用户实机确认双指斜移仍会被吸成单轴。此前合成双轴事件只验证了画布处理，不能代表实体触控板。实际运行时为 Chromium 156.0.8078.109；[这一版本的 Windows helper](https://github.com/chromium/chromium/blob/156.0.8078.109/content/browser/renderer_host/direct_manipulation_helper_win.cc#L74-L84) 在应用收到输入前开启了两项 DirectManipulation 锁轴配置。
- 新增 F19 → 设置 → 触控板诊断。用户主动触发后只汇总八秒内浏览器收到的单轴和双轴位移事件，将最近一次计数保存在本机，不收集原始坐标、按键或草稿，也不上传。模拟数据验证统计入口；实体采样和原生修复仍待验证。
- [原生去锁轴候选补丁](../desktop/patches/chromium-windows-touchpad-unrail.patch) 仅用于后续独立构建：保留横纵位移、惯性和捏合，移除两项锁轴。补丁不是现有便携版，也不更改系统级设置；上线前先在同一台实体电脑测试斜滑、不抬手变向、捏合和普通鼠标。

### 同日勘误：换色提示随视线，文字不要描边

- 换色提示从右上角移到输入光标旁；不在输入时放在画布指针附近，定位不可用时放在画布中间，靠边时避让。按住 F17/F18 不连续越过多色，明确的功能键允许随硬件重映射送达。
- 若能收到 F17/F18 但中文候选尚未提交，记住要换的笔色，候选提交后只影响下一笔；不丢快捷键，也不对候选或原有字重新染色。实体输入法、用户键盘映射仍需人工验证。
- 去掉文字外的纸色描边。它原本是为擦过文字的连线保持清晰，叠在纸纹上看起来像棕色底；现在靠自然线路避让，不用文字包底。

### 同日勘误：Enter 建的并列项要一起移动

- Enter 创建同级时记录显式分组，组内任一项悬停后拖动，会统一平移整组，不改变成员之间的位置差、父子标记或连线，整组移动可以一次撤销。快速拖动仍然是拉线，不是搬动。
- 没有标记的旧草稿不按临近、编号或连线样式推断分组。导出／导入和自动保存要保留组标记；独立块和 Tab 生成的子块不会被拖入同级组。
