# 原始设计想法与思维场景

## 从现有纸笔习惯做减法

纸上会用空间位置、连线、圈画与不同颜色表达思考。目标不是复刻所有笔迹，而是提炼高频且能降低歧义的动作。第一轮以红色合并大多数强调动作，不单独为圈、下划线、加粗堆叠工具。四色语义：黑＝正文；红＝重点、提醒和易错；蓝＝启发或自己的好观点；铅笔灰＝个人补记、假设或待定。

当前交互：点空白即输入，没写就释放；Enter 向下并列，输入 `1.` 可续编号，数字轻量显示；Tab 从当前文字块生出带单箭头的子块，子块可以继续生成下一层；从文字块拖向空白拉线并开始写，拖向已有块则建立连接。当前键位为 F18 循环四色、F17 循环选中线的箭头，替代此前讨论的 Caps+Q/E、Alt+Q/E 及 F17–F20 直接选四色方案。本地 Caps 映射由用户自行处理，应用只识别最终虚拟键；F19 打开笔颜色、线型等工具菜单，F20 不占用。颜色可应用于选中文字、选中的对象或后续输入，并保留顶栏色点。中文候选确认不得误触并列或分支。滚轮和触控手势负责浏览；属性通过选中或右键打开，多选作为后续待验方向。

线条的样式、方向、颜色应是相互独立的属性。允许实线/虚线，无箭头/正向箭头/反向箭头/双向箭头，颜色可选。连线应优先保持自然的曲线和清楚的出入方向，尽量避开文字，但允许少量交叠；不为了完全避字而出现方形绕路、长距离折返，也不擅自移动文字。密集关系的表现及手动调整路径的需要仍待实测。靠在线旁边的字既可能是关系说明，也可能是独立想法：允许用户明确附到连线或保留成普通块，不靠距离自动判定。先让线保持无名字；只有不写就可能误解时再加短关系词。

## 2026-11-25 · 编辑窗口的本轮要求

这些条目记录本轮用户确认的方向及对应实现目标。先补齐编辑所需的能力，再减少常驻控件；不把后续场景探索当成已经交付的功能。

### 输入与视觉

- 把画布作为直接写字的编辑窗口。普通文字和输入状态都不显示明显的文本框，移除「写在这里…」占位字和干扰输入的悬浮说明；选字仍保留必要的选区与光标反馈。
- 使用参照拾页的暖橘纸面，基础色为 `#fce3bf`。输入区域和画布使用同一纸面，不在聚焦后突然出现白色卡片。
- 去掉左下角保存说明和右下角工具按钮；常用操作集中在顶栏、对象菜单及键盘入口。正常保存静默，只有真实保存失败才在顶栏显示简短提示。
- 左上角和标签的草稿名称由用户修改，默认使用中性的「未命名」；不根据正文或日期擅自重命名。

### 编辑完整性

- 自动保存采用最长 150 ms 的有界合并调度：持续输入也安排写入，不无限等待停笔。Ctrl+S 立即写入；切换标签、页面离开和关闭前处理当前待保存内容。
- 文字输入、局部颜色、生成块和连线、修改关系、移动位置使用统一的撤销/重做体系。创建子块及其箭头视为一个结构动作，避免撤销后留下孤立关系；原生文本撤销和应用撤销不能重复执行。
- Tab 必须从当前块生成子块，并立即把输入焦点交给新块；再次 Tab 能生成子子块。Enter 生成当前层同级项，Shift+Enter 在同一个块内换行。候选词正在组词或确认时，Enter、Tab 不应生成结构。
- F17 / F18 沿「黑 → 红 → 蓝 → 灰 → 黑」循环，其中 F18 向右、F17 向左。选中文字时只改变该范围；无文字选区时按当前所选对象或后续输入范围处理。色点与快捷键调用同一操作，不新增记忆负担。

### 多标签与数据保留

- 可新建、切换、重命名、关闭和重新打开草稿标签。关闭只改变打开状态，不删除草稿；重新打开后内容仍在。
- 各草稿分别保存内容、关系、视野和当前笔色；切换时不得把上一页尚未落盘的内容写进下一页。
- 新工作区使用 v2 存储。原 v1 单草稿迁入一个标签，并保留旧键；遇到无法读取的数据，不用新空白画布覆盖原记录。
- JSON 导入另开草稿，保留已打开内容。普通草稿依然先在本机保存，这一轮不引入云同步或复杂文件系统。

### 触控板与鼠标

- 触控板双指平移同时保留横、纵位移，支持连续斜向移动，不做轴锁定；微小位移累积保留，不因为四舍五入而卡住。
- 捏合缩放围绕指针或手势中心进行；缩放后原关注位置保持稳定。双指平移不得意外变成文字块拖动或创建新文字。
- 鼠标支持空白拖动画布、空格拖移、滚轮平移以及缩放操作；触控板和鼠标共用坐标与选择规则，不要求频繁切换常驻模式。
- 正在编辑的文字可用 Alt+拖动调整位置，撤销移动后恢复原光标。鼠标切换标签再回来，也恢复原选区与编辑位置。
- 键盘可微调所选块；没有选择时可平移画布。移除底部工具后，缩放、回到全图、对象属性等能力仍可从键盘或顶栏找到。

### 追加：走线以自然和美观为先

- 用户明确不满意原有方形避让路线，并允许一定程度的线条与文字交叠。
- 默认使用简洁、顺滑的曲线；布局不应因少量文字障碍变成矩形电路板走线。
- 文字障碍作为软约束，与曲线长度、弯曲程度、出入方向和线线交叉一起权衡。宁可少量擦过，也不要大幅折返。
- 同一对对象的双向关系或两条反向关系仍可区分；线型、方向、颜色与说明保持独立可编辑。
- 只改变连线显示，保留已有文字坐标和关系数据。允许交叠处用细微纸色文字描边保持可读，不添加文本框或遮挡卡片。
- 使用普通树状、密集交叉及长文字障碍三组样例检查，重点看是否自然、是否易跟随，不以零碰撞作为唯一标准。

### 本轮快捷键约定

| 上一种 / 下一种颜色 | F17 / F18 |
| 同级 / 子块 / 块内换行 | Enter / Tab / Shift+Enter |
| 新的独立想法 | Ctrl+Enter |

### 验收边界

浏览器自动化可以验证：输入后新建子块及子子块、同级结构、局部改色、撤销/重做、标签切换隔离、关而不删、旧数据迁移、刷新恢复、双轴滚动和缩放锚点。模拟组合事件可以检查输入法防误触逻辑。

实体 Windows 上仍需复验真实中文输入法候选、触控板惯性和捏合手感、鼠标滚轮及本地 F17/F18 映射。浏览器中的合成事件或 Linux 预览截图不等于这些设备行为已经实测。后续纸笔导入、数学输入与 AI 能力继续单独验证。

## 用场景试，不靠功能数选设计

| 场景 | 试一次具体动作 | 判断是否有用 |
| --- | --- | --- |
| 发散想法 | 写「为什么我看文献总停在开头？」并列写两个解释；从第一个拉出一个反例，再记一条无关想法；回来继续第一个。 | 无需先排版；几秒内能找回主线，且不必把无关内容硬接进树。 |
| 长程调研 | 写一个问题，分出两路证据；给反向证据加连线；将支线发现跨连回原问题，把猜测标灰、启发标蓝。 | 过一段时间，能看出什么是原问题、证据、反例和自己的推测，而不是得到一张更复杂的图。 |
| 数学推导 | 解一道有两种方法的题：主路径顺序写，在卡住的那步开旁支，红标一个易错条件，最后回到原推导。 | 书写速度、对齐和式子完整性比节点数重要；不强迫用 LaTeX 或把每行公式做成卡片。 |
| 听课或阅读 | 把听到的定义当正文，临时记下一个问题，回看时找出一条有启发的观点，保留原材料与个人判断的差别。 | 写时不用判断每条的类别，回看才补结构；颜色在打印灰度下仍有替代读法。 |
| 比较决策 | 并列写两个可选方案，共用一条约束，给互相影响的因素画双箭头，暂不能确定的连线用虚线。 | 语义能被读懂，实线和虚线的含义不被软件强制规定；没有必要的连线就不画。 |
| 纸笔与电脑来回 | 先在纸上写一页，再拍照作为底稿。手动校对几处块与线后改写；把数字版打印出来，继续手写标注。 | 纸面布局、颜色与关系尽量保留；识别有歧义时保留原图和待校对状态，而不是让 AI 猜。 |

## 验证顺序

1. 用一条主线、一个相关分支和一个无关念头试「写下 → 连线 → 回到原处」，对比纸、纯文本和画布，留意中文候选确认、鼠标切换和找回上下文。
2. 用一页不含私人信息的样例区分关系标签、独立文字和视觉强调。只保留能减少操作或歧义的惯例。
3. 再试纸笔往返、数学输入和按需 AI。可先做打印/PDF 输出和原图对照导入；结构化识别、手写、学习模式和长期整理能力分开评估。

## 保留结构，不增加写字时的负担

- 纸上的无框表格更多是并排对照或分栏，不一定需要真的插表。先试对齐、留白和并列；只有列名和列对应关系必须被读出来时，再考虑轻量表格。
- 有些长分隔线只是纸面放不下，不要自动解释成主题断开。无限画布能避免为了换页而画线，只有确实要分组时才记组。
- 底层按「文字块 + 关系 + 一组可选标记」保存。位置、线条外观与关系含义分开；普通文本保留可读性。以后让 AI 读取用户挑选的块、来源与相邻关系，并可把整理建议另存为草稿，而不是自动改写。
- 能记录的是真实写下的草稿步骤和修改（将来若加入版本历史），不是推断作者没写出来的想法。数字草稿默认本地保存，原始手稿和私人内容不进入公开仓库。
