# 原始设计想法与思维场景

## 从现有纸笔习惯做减法

纸上会用空间位置、连线、圈画与不同颜色表达思考。目标不是复刻所有笔迹，而是提炼高频且能降低歧义的动作。第一轮以红色合并大多数强调动作，不单独为圈、下划线、加粗堆叠工具。四色语义：黑＝正文；红＝重点、提醒和易错；蓝＝启发或自己的好观点；铅笔灰＝个人补记、假设或待定。

草案交互：点空白即输入，没写就释放；Enter 向下并列，输入 `1.` 可续编号，数字轻量显示；Tab 从当前卡片生出带单箭头的子卡片；从卡片拖向空白拉线并开始写，拖向已有卡片则建立连接。Caps+Q/E 切换四色是待试键位，需允许给正在写、未来输入及选中内容改色，并保留触控按钮。中文候选确认不得误触并列或分支。滚轮和触控手势负责浏览；属性通过选中或右键打开，多选作为后续待验方向。

线条的样式、方向、颜色应是相互独立的属性。允许实线/虚线，无箭头/单箭头/双箭头，颜色可选。曲线拟用于降低遮挡，但自动绕开其他卡片和手动改弯曲程度尚待比较。靠在线旁边的字既可能是关系说明，也可能是独立想法：允许用户明确附到连线或保留成普通卡片，不靠距离自动判定。先让线保持无名字；只有不写就可能误解时再加短关系词。

## 用场景试，不靠功能数选设计

| 场景 | 试一次具体动作 | 判断是否有用 |
| --- | --- | --- |
| 发散想法 | 写「为什么我看文献总停在开头？」并列写两个解释；从第一个拉出一个反例，再记一条无关想法；回来继续第一个。 | 无需先排版；几秒内能找回主线，且不必把无关内容硬接进树。 |
| 长程调研 | 写一个问题，分出两路证据；给反向证据加连线；将支线发现跨连回原问题，把猜测标灰、启发标蓝。 | 过一段时间，能看出什么是原问题、证据、反例和自己的推测，而不是得到一张更复杂的图。 |
| 数学推导 | 解一道有两种方法的题：主路径顺序写，在卡住的那步开旁支，红标一个易错条件，最后回到原推导。 | 书写速度、对齐和式子完整性比节点数重要；不强迫用 LaTeX 或把每行公式做成卡片。 |
| 听课或阅读 | 把听到的定义当正文，临时记下一个问题，回看时找出一条有启发的观点，保留原材料与个人判断的差别。 | 写时不用判断每条的类别，回看才补结构；颜色在打印灰度下仍有替代读法。 |
| 比较决策 | 并列写两个可选方案，共用一条约束，给互相影响的因素画双箭头，暂不能确定的连线用虚线。 | 语义能被读懂，实线和虚线的含义不被软件强制规定；没有必要的连线就不画。 |
| 纸笔与电脑来回 | 先在纸上写一页，再拍照作为底稿。手动校对几处块与线后改写；把数字版打印出来，继续手写标注。 | 纸面布局、颜色与关系尽量保留；识别有歧义时保留原图和待校对状态，而不是让 AI 猜。 |

## 验证顺序

1. 用一条主线、一个相关分支和一个无关念头试「写下 → 连线 → 回到原处」，对比纸、纯文本和画布，留意中文候选确认、鼠标切换和找回上下文。
2. 用一页不含私人信息的样例区分关系标签、独立文字和视觉强调。只保留能减少操作或歧义的惯例。
3. 再试纸笔往返、数学输入和按需 AI。可先做打印/PDF 输出和原图对照导入；结构化识别、手写、学习模式和长期整理能力分开评估。

## 保留结构，不增加写字时的负担

- 纸上的无框表格更多是并排对照或分栏，不一定需要真的插表。先试对齐、留白和并列；只有列名和列对应关系必须被读出来时，再考虑轻量表格。
- 有些长分隔线只是纸面放不下，不要自动解释成主题断开。无限画布能避免为了换页而画线，只有确实要分组时才记组。
- 底层按「文字块 + 关系 + 一组可选标记」保存。位置、线条外观与关系含义分开；普通文本保留可读性。以后让 AI 读取用户挑选的块、来源与相邻关系，并可把整理建议另存为草稿，而不是自动改写。
- 能记录的是真实写下的草稿步骤和修改（将来若加入版本历史），不是推断作者没写出来的想法。数字草稿默认本地保存，原始手稿和私人内容不进入公开仓库。
