# 草稿纸

一个以纸笔习惯为起点的中文思考草稿工具。先把脑子里的东西写下来，再用很少的动作，把并列、分支和跨线联系表达清楚。

## 试用

直接用现代浏览器打开 `dist/index.html`。无需安装或登录。网页原型在当前浏览器里保存草稿，换设备前请导出 JSON。

- 在空白处点一下就写；空卡离开后不保留。Enter 写同级下一条，Tab 写带单箭头的分支。
- 用四色表达语气：黑为正文，红为重点、易错和提醒，蓝为启发和好观点，灰模拟铅笔，留给个人想法和待定内容。
- 从卡片的连线把手拖出，可连接已有卡片或在空白处新建。线条可独立调整实线/虚线、无/单/双箭头和颜色。
- 先看 [原始设计想法与思维场景](docs/design.md)。这版只试编辑体验，不等同于手写识别、AI 分析或设备同步已经实现。

## 项目原则

先捕捉，再整理。视觉重点不要求先挑标签；写下箭头也不必须当场命名。AI 默认不介入，只有主动选中一段内容请求帮助时，才给可撤销的建议，不覆盖草稿原文。普通文本、调研和数学先分别试验，不强行共用一套输入方式。
