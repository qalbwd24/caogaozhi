# 草稿纸

一个以纸笔习惯为起点的中文思考草稿工具。先把脑子里的东西写下来，再用很少的动作，把并列、分支和跨线联系表达清楚。

## 试用

Windows x64：完整解压便携包，再打开 `草稿纸.exe`，同目录的运行时文件要保留。详见 [Windows 构建与运行](desktop/README.md)。也可以用现代浏览器打开 `dist/index.html` 试用；桌面和浏览器的数据各自本地保存，迁移请用 JSON。

- 在空白处点一下就写；空块离开后不保留。输入时只有文字和光标，不显示文本框、占位字或悬浮说明。
- Enter 写同级下一条，Tab 写带单箭头的子块；在子块继续 Tab 可写子子块。Shift+Enter 在当前块内换行，中文候选确认不会同时创建分支。
- 多份草稿在顶栏标签间切换，名称由自己填写。关闭标签只收起草稿，之后可以重新打开；每份草稿保留自己的内容、视野和笔色。
- 输入过程中自动保存，正常保存保持安静；Ctrl+S 立即保存。文字、颜色、连线和位置操作都可以撤销、重做。旧版单草稿会迁入新工作区，原始旧数据键保留。
- 顶栏随选中内容变化：未输入时是下一笔，编辑时显示输入或选区色，选线时显示线色、线型和箭头。
- F17 向左、F18 向右循环黑、红、蓝、灰；可在本地把常用组合键映射为这两个虚拟按键。F19 唤起分层工具菜单，F20 暂不占用。写到一半可换笔；拖选一段再改色只改选区，可撤销。黑为正文，红为重点、易错和提醒，蓝为启发和好观点，灰模拟铅笔，留给个人想法和待定内容。
- 快速拖文字块或从线的把手拖出，可连接已有块或在空白处新建。线条可独立调整实线/虚线、无/单/双箭头和颜色。走线以自然曲线为先，柔和避让文字，允许少量交叠；不再为了避字绕出方形大圈。反向关系分开成弧，关系说明尽量错开。
- 暖米纸底、细纸纹和淡棕点阵，不用图案壁纸；底部不放常驻保存文字或工具。浏览器交给画布的横纵位移等权处理，捏合在指针附近缩放；Windows 原生输入层可能先锁轴；如实际斜移仍受限，可在 F19 → 设置 → 触控板诊断查看应用收到的两轴情况。按住鼠标滚轮拖动画布；空白裸拖留空。文字块悬停到抓手后直接拖动移动，快速拖动拉线。
- 先看 [原始设计想法与思维场景](docs/design.md) 和 [需求与改动记录](docs/requirements-log.md)。这版只试编辑体验，不等同于手写识别、AI 分析或设备同步已经实现。

## 常用键位

| 动作 | 按键 |
| --- | --- |
| 上一种 / 下一种颜色 | F17 / F18 |
| 分层工具菜单 | F19；↑↓ 选择，→ 进入，← 返回，Enter 执行，Esc 关闭 |
| 并列下一条 / 子块 / 块内换行 | Enter / Tab / Shift+Enter |
| 记一条独立想法 | Ctrl+Enter |
| 撤销 / 重做 | Ctrl+Z / Ctrl+Y 或 Ctrl+Shift+Z |
| 立即保存 | Ctrl+S |
| 新建草稿标签 | Ctrl+Alt+N；桌面版也可 Ctrl+T |
| 上一个 / 下一个标签 | Ctrl+PageUp / Ctrl+PageDown |
| 重命名当前草稿 | F2 |
| 关闭当前标签 | 桌面版 Ctrl+W；也可点击标签关闭按钮 |
| 重新打开已关闭的草稿 | Ctrl+Alt+T；桌面版也可 Ctrl+Shift+T |
| 放大 / 缩小 / 显示全部 | Ctrl++ / Ctrl+- / Ctrl+0 |
| 微调所选块；没有选择时平移画布 | Alt+方向键 |
| 当前对象属性 | Shift+F10 |
| 导出 / 导入 JSON | Ctrl+Shift+E / Ctrl+O |
| 帮助 | F1 |

浏览器自身占用的 Ctrl+T、Ctrl+W、Ctrl+Shift+T 使用上表的替代键或标签按钮；桌面版可在应用内处理这些键。键盘快捷键与顶栏、标签和对象菜单调用同一动作，避免出现只有鼠标才能完成的基本流程。

## 保存与验证边界

工作区保存在使用当前应用的设备上；多个标签不是云端同步。保存成功不弹通知，真正写入失败时在顶栏显示简短提示，当前内容仍留在编辑器中。关闭标签不删除草稿，导入不会替换已有标签。

本轮 33 项自动化检查已通过，覆盖子块层级、键盘编辑、撤销重做、标签隔离、刷新恢复和双轴滚动事件；另检查了多层分支、密集交叉与长段文字三种走线布局。详见[验证记录与实际界面](docs/verification-v0.3.md)。实际 Windows 触控板的手感、中文输入法候选行为及用户本地 F17/F18 映射仍需在桌面运行包中复验。

## 项目原则

先捕捉，再整理。视觉重点不要求先挑标签；写下箭头也不必须当场命名。后续 AI 能力的原则是默认安静，主动请求时给可撤销的建议，不覆盖草稿原文。普通文本、调研和数学先分别试验，不强行共用一套输入方式。
